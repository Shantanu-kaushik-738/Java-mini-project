# Hotel Room Reservation System (Java)

This repository contains a **Java-based Hotel Room Reservation System** project.  
It demonstrates the use of **Object-Oriented Programming (OOP)** concepts such as classes, interfaces, encapsulation, and modular design.

---

## Features
- View room status (Available / Occupied).
- Book a room with type selection (Deluxe, Double, Single).
- Cancel a booking with penalty calculation (20% of canceled days).
- Bill calculation based on room type and number of days.
- Room management using arrays and encapsulated `Room` class.

---

## Technologies Used
- Java (Core OOP concepts)
- Scanner class for user input
- Interface (`Service`) for bill calculation

---

## Files Included
- `Main.java` → Entry point of the system.  
- `Room.java` → Room class with attributes and methods.  
- `Hotel.java` → Hotel class managing rooms, booking, and cancellation.  
- `README.md` → Documentation of the project.  
- `Project_Documentation.pdf` → Detailed explanation of system design and flow.
